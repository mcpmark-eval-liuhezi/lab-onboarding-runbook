## Accounts and access

Ask your onboarding buddy to submit the account request form for your lab email, GitHub organization membership, and shared drive access. Most accounts are ready within two business days.

## Workstation setup

Install the baseline toolchain (git, Python, and the lab editor configuration) using the setup script linked in the internal wiki. Post a screenshot of the completed setup checklist in the lab channel so we know you are unblocked.

## First code review

Pick any open pull request tagged "good-first-review" and read it end to end before commenting.
